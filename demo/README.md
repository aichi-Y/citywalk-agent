# demo 目录说明

本目录存放参赛材料：

- `演示截图/`：正常规划、扰动重规划两个场景的界面截图
- `录屏/`：3—5 分钟演示视频（必须包含"扰动自动重规划"片段）
- 命名建议：`01-正常规划-天津.png`、`02-扰动重规划-闭园.png`、`demo.mp4`

## 录屏脚本（对应教程 2.4）
1. 0:00—0:40 痛点引入
2. 0:40—2:00 正常场景：输入【天津、2天、预算800、偏好古迹+美食】→ 生成路线、预算统计、讲解词
3. 2:00—3:30 扰动场景：追加输入【古文化街临时闭园，明天有大雨】→ Agent 自动更换景点、调整顺序、重新核算预算（核心镜头！）
4. 3:30—4:00 文化讲解词展示
5. 4:00—5:00 架构图与收尾
