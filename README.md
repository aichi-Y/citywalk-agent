# 城墙漫游记 —— 城市微旅行智能规划 Agent

> 全国人工智能应用创新大赛参赛作品
> 输入城市 / 出行天数 / 总预算 / 偏好标签，Agent 自动检索景点开放时间、票价、客流、本地美食，在预算约束下规划"特种兵式"微旅行路线；遇到天气变化、景点临时闭园等突发事件，**自动重规划**并生成地道的本地文化讲解词。

## ✨ 核心亮点

1. **Agent 自主规划**：先检索（景点票价/开放时间/预约要求/客流）→ 再规划（预算约束 + 地理顺路 + 特种兵式高强度游览）→ 后核验（独立预算核算层，双保险防超支）
2. **扰动自动重规划（核心创新点）**：收到【XX景点今日闭园 / 明天有大雨】等突发事件后，自动更换景点、调整顺序、重新核算预算，并逐条说明调整理由
3. **RAG 文化讲解词**：基于本地知识库（knowledge/ 目录）生成口语化、有故事感的讲解词，避免网上套话与幻觉
4. **双形态交付**：Streamlit Web 界面（加分版，支持一键部署）+ 控制台版（快速验证）

## 🗂️ 项目结构

```
citywalk-agent/
├── main.py            # 主程序入口（Streamlit Web 界面 + Agent 调用胶水层）
├── console_demo.py    # 极简控制台版（快速验证链路）
├── agent_config.json  # Agent 配置（名称/场景/系统提示词/工具开关，与 JoyCode 智能体面板一致）
├── requirements.txt   # 依赖清单
├── knowledge/         # 知识库素材（城市文旅资料、古迹介绍、美食）
├── static/            # 静态资源
├── demo/              # 演示截图、录屏
└── README.md          # 本文件
```

## 🚀 本地运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置模型：复制 .env.example 为 .env，填入你的 API Key
#    （兼容 OpenAI 接口规范的服务均可：智谱/DeepSeek/通义/Kimi）

# 3. Web 版启动（推荐）
streamlit run main.py --server.port=8000

# 或控制台版
python console_demo.py
```

## ☁️ JoyCode 一键部署

- 启动命令：`streamlit run main.py --server.port=8000`
- 在 JoyCode 项目页点击【一键部署】，获得公网链接
- 注意赛事免费部署实例有运行时长限制，提交与答辩期间保证链接可用
