# 智漫游 —— 城市旅行智能规划 Agent

> 全国人工智能应用创新大赛参赛作品
> 输入城市 / 出行天数（1—5 天）/ 总预算 / 偏好标签（美食、古迹、免费景点、打卡热点、自然风光、文博展馆、休闲慢逛），Agent 自动检索景点开放时间、票价、客流、本地美食，在预算约束下规划路线，**逐景点配图并给出景点间交通衔接**；遇到天气变化、景点临时闭园等突发事件，**自动重规划**并生成地道的本地文化讲解词。

## ✨ 核心亮点

1. **Agent 自主规划**：先检索（景点票价/开放时间/预约要求/客流）→ 再规划（预算约束 + 地理顺路 + 特种兵式高强度游览）→ 后核验（独立预算核算层，双保险防超支）
2. **扰动自动重规划（核心创新点）**：收到【XX景点今日闭园 / 明天有大雨】等突发事件后，自动更换景点、调整顺序、重新核算预算，并逐条说明调整理由
3. **RAG 文化讲解词**：基于本地知识库（knowledge/ 目录）生成口语化、有故事感的讲解词，避免网上套话与幻觉
4. **逐景点配图与交通衔接**：每个景点自动匹配配图（古迹/地标/文博/自然/美食/夜景/街区 七类素材），并给出「方式+线路+耗时+费用」的交通衔接，行程可直接照着走
5. **双形态交付**：Streamlit Web 界面（加分版，支持一键部署）+ 控制台版（快速验证）

## 🗂️ 项目结构

```
citywalk-agent/
├── main.py            # 主程序入口（Streamlit Web 界面 + Agent 调用胶水层）
├── console_demo.py    # 极简控制台版（快速验证链路）
├── agent_config.json  # Agent 配置（名称/场景/系统提示词/工具开关，与 JoyCode 智能体面板一致）

├── knowledge/         # 知识库素材（城市文旅资料、古迹介绍、美食）
├── static/images/     # 景点配图素材（7 类，离线可用）
├── demo/              # 演示截图、录屏
└── README.md          # 本文件
```

## 🚀 本地运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置模型：复制 .env.example 为 .env，填入你的 API Key
#    （兼容 OpenAI 接口规范的服务均可：智谱/DeepSeek/通义/Kimi）

# 3. Web 版启动（推荐）
streamlit run main.py --server.port=8000

# 或控制台版
python console_demo.py
```


## 🖼️ 景点照片与社区玩法参考

- 每个景点左侧为**真实实拍照片**（非插画）：共 35 个京津冀景点，源自 Wikimedia Commons 开放许可素材（CC BY / CC BY-SA / 公有领域），
  统一裁切 4:3、压缩到 800×600，随仓库提交，离线可用；来源清单见 `static/images/photos_credit.json`。
- 没有专属实拍的景点，使用**同类实景照片**兜底（不虚构为某景点）。
- 每条行程可一键跳转「小红书」站内搜索（`xiaohongshu.com/search_result?keyword=城市+景点`），
  用于核对真实游记、拍照机位与避坑信息；模型同时输出 `xhs` 字段，给出一句社区实拍经验。
- 说明：小红书未提供公开数据接口且限制机器访问，因此**不做实时抓取**，
  采用「社区经验入提示词 + 站内搜索直达」的方式接入，保证信息可追溯、链接可验证。
- 抓取与裁切脚本：`tools/fetch_spot_photos.py`、`tools/redownload_by_hash.py`（可复现）。
